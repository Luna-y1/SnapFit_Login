# SnapFit - Login and Registration Interface

## Project Description

SnapFit is a Flutter mobile application interface developed as part of a Flutter assignment. The project demonstrates the use of Flutter widgets, layouts, text fields, buttons, navigation, and basic form validation.

## Features

### Login Page
- SnapFit application name
- Email input field
- Password input field
- Show/Hide password functionality
- Login button
- Forgot Password option
- Navigation to Registration page
- Basic form validation

### Registration Page
- SnapFit application name
- Full Name input field
- Email input field
- Password input field
- Confirm Password input field
- Show/Hide password functionality
- Create Account button
- Password matching validation
- Navigation back to Login page
